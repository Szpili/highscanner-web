# highscanner-web

Marketing site for [HighScanner](https://highscanner.pl) — a price tracker for
medical cannabis in Polish pharmacies.

Stack:

- Next.js 16 (App Router, TypeScript)
- Tailwind CSS v4
- Deployed on Vercel
- DNS via Cloudflare

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm run start
```
